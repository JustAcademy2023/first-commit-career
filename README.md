# First Commit Career

A playful, single page guide to **how freshers can get their first software development job**, told as a git log. Pick a lane, build projects, polish your resume, apply weekly and walk into interviews calmly.

## What is inside

- A hero with a typing commit message and a scrolling ticker of junior developer roles
- A five commit roadmap from first language to first offer
- Starter courses and a featured MERN bootcamp, all in Mumbai
- A reading list of four career guides

## Run it

It is one static file. Open `index.html` in a browser, or publish with GitHub Pages: **Settings, Pages, Deploy from branch, main, root**.

## Tech

Plain HTML, CSS and a few lines of JavaScript. Fonts: Bricolage Grotesque and DM Sans from Google Fonts. Responsive, keyboard friendly, and respects reduced motion.
